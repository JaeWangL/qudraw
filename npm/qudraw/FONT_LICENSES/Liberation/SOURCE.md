# Liberation Sans 1.05 notices

The unchanged `LiberationSans-Regular.woff2` in this package identifies itself as Liberation Sans version 1.05 (Ascender/Red Hat, 2007/2009). This is the legacy release, whose license differs from the OFL used by newer Liberation releases.

- `LICENSE` is the complete legacy Liberation license and font exceptions, preserved from [Fedora's archived license page](https://fedoraproject.org/w/index.php?title=Licensing:LiberationFontLicense&oldid=66741).
- `COPYING` is the GNU General Public License version 2, from [GNU's official license text](https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt).
- The unchanged imported font binary is available at `packages/excalidraw/fonts/Liberation/LiberationSans-Regular.woff2` in [qudraw](https://github.com/jaewangl/qudraw), and in the original [Excalidraw source snapshot](https://github.com/excalidraw/excalidraw/tree/a2ec2889babf7d2295469c6d90ebe77fae57df84/packages/excalidraw/fonts/Liberation).

No glyphs or font names were modified for this package.
